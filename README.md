One sentence (122 characters) explaining the modern internet to a time traveler who has just stepped out of the year 1800. Every word predates 1800: a web the traveler knows, a whisper, London, Boston, a candle. One picture, no list of features.

> Imagine a web spun across the whole earth, where a whisper in London reaches Boston before the candle beside you flickers.

## Run it

```sh
node main.ts
```

This writes the sentence to `/output/entry.txt` (122 characters, one sentence, no trailing newline), deterministically.
